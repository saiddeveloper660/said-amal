🌙 Said Amal

Said Amal is a modern and user-friendly Islamic Dua & Zikr application developed by Said Developer.

The app is designed to help users easily read, search, save, listen to, and share daily Islamic duas and adhkar.

✨ Features

- 📖 Islamic Duas & Adhkar
- 🔍 Fast Dua Search
- ❤️ Favorite / Bookmark Duas
- 🔊 Dua & Zikr Audio
- 📥 Offline support
- 🔔 Daily reminders
- 📤 Share Dua
- 📋 Copy Dua
- 🌙 Dark Mode
- ⚙️ Customizable Settings
- 📱 Clean and modern UI
- 🚀 Fast and lightweight

📱 App Sections

- Home
- Dua Categories
- Favorites
- Audio
- Daily Reminders
- Settings
- About

🛠️ Technology

- Flutter
- Dart
- Android
- Local Storage
- Firebase-ready architecture

📦 Installation

Download the latest APK from the Releases section of this repository and install it on your Android device.

«Make sure you download the APK from the official GitHub Releases page.»

🚀 Development

Clone the repository:

git clone [https://github.com/YOUR_USERNAME/said-amal.git](https://github.com/saiddeveloper660/said-amal)

Go to the project directory:

cd said-amal

Install dependencies:

flutter pub get

Run the application:

flutter run

🔐 Privacy & Security

Said Amal is designed with privacy and security in mind.

The application does not request unnecessary permissions such as contacts, SMS, call logs, camera, microphone, or location unless a future feature specifically requires them.

Never add API keys, passwords, Firebase secrets, or other private credentials directly to the public repository.
